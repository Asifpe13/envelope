# מעטפות · Envelope

Lightweight Hebrew RTL Progressive Web App for tracking monetary gifts at life events, building a future guest list, and comparing gifts given vs. received (**הריזיקה**) — with real-time sync between two phones via Supabase and a shared space code (no email/password).

## Quick start

See **[SETUP.md](./SETUP.md)** for Supabase SQL, `.env`, Vercel deploy, and iPhone “Add to Home Screen”.

```bash
cp .env.example .env   # fill in Supabase URL + anon key
npm install
npm run dev
```

## Stack

Vite · React · TypeScript · Tailwind CSS · Lucide · Supabase Realtime · PWA
